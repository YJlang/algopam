# 엑셀 함수 기초: RANK, SUMIF, COUNT, 문자열, 반올림 함수 한 번에 실습하기

엑셀 함수를 처음 배울 때 제일 헷갈리는 부분은 함수 이름보다도 "어디를 고정해야 하는지", "자동 채우기를 했을 때 왜 값이 이상해지는지"인 것 같다.

이번 글에서는 자주 쓰는 기초 함수들을 하나씩 정리하면서, 직접 따라 해볼 수 있는 작은 실습 표까지 같이 만들어보려고 한다.

## 먼저 실습 표 만들기

아래 표를 엑셀에 그대로 입력해보자. 열 위치까지 맞추면 뒤에 나오는 수식을 그대로 따라 치기 쉽다.

| 행 | C열: 지점 | D열: 매출 | E열: 담당자 | F열: 코드 | G열: 점수 |
| --- | --- | ---: | --- | --- | ---: |
| 4 | 중부 | 1200000 | 지민 | ABCDE | 88 |
| 5 | 남부 | 750000 | 민수 | KOR202 | 95 |
| 6 | 중부 | 980000 | 수아 | QWER1 | 72 |
| 7 | 동부 | 1100000 | 현우 | SALE7 | 88 |
| 8 | 남부 | 620000 |  | NOTE9 | 100 |
| 9 | 중부 | 830000 | 유진 | MID45 | 64 |
| 10 | 서부 | 1500000 | 도윤 | RIGHT | 91 |

E8은 일부러 빈칸으로 둔다. `COUNTBLANK`를 연습하기 위해서다.

## 1. 셀 참조 3가지: 상대 참조, 절대 참조, 혼합 참조

엑셀 함수에서 `$` 표시는 "자동 채우기를 해도 이 위치는 움직이지 마"라는 뜻이다.

### 상대 참조

```excel
G4
```

그냥 `G4`처럼 쓰면 상대 참조다. 이 수식을 아래로 자동 채우기 하면 `G5`, `G6`, `G7`처럼 같이 움직인다.

예를 들어 H4에 아래 수식을 쓰고 아래로 채우면,

```excel
=G4+10
```

H5에서는 자동으로 이렇게 바뀐다.

```excel
=G5+10
```

이런 경우에는 셀이 같이 움직이는 게 자연스럽다.

### 절대 참조

```excel
$G$4:$G$10
```

`$G$4:$G$10`처럼 열 문자와 행 번호 앞에 모두 `$`를 붙이면 절대 참조다.

자동 채우기를 해도 범위가 계속 `G4:G10`으로 고정된다. 순위나 합계처럼 "비교 대상 전체 범위"가 계속 같아야 할 때 꼭 필요하다.

예를 들어 점수 순위를 구할 때 비교 범위는 항상 G4부터 G10까지여야 한다.

```excel
=RANK(G4, $G$4:$G$10, 0)
```

여기서 `G4`는 아래로 내려가며 `G5`, `G6`처럼 바뀌어야 한다. 하지만 `$G$4:$G$10`은 전체 점수 범위라서 고정되어야 한다.

### 혼합 참조

```excel
$G4
G$4
```

혼합 참조는 열이나 행 중 하나만 고정하는 방식이다.

- `$G4`: G열은 고정하고, 행 번호는 움직인다.
- `G$4`: 열은 움직이고, 4행은 고정한다.

처음에는 상대 참조와 절대 참조만 확실히 이해해도 충분하다. 표를 가로와 세로로 동시에 복사하는 문제를 풀 때 혼합 참조가 자주 등장한다.

참조를 바꿀 때는 셀 주소에 커서를 둔 뒤 `F4`를 누르면 된다.

```text
G4 -> $G$4 -> G$4 -> $G4 -> G4
```

이 순서로 바뀐다.

## 2. RANK: 점수 순위 구하기

`RANK` 함수는 어떤 값이 범위 안에서 몇 등인지 구할 때 쓴다.

```excel
=RANK(기준값, 범위, [정렬방식])
```

- 기준값: 순위를 알고 싶은 값
- 범위: 비교할 전체 값들
- 정렬방식: 생략하거나 `0`이면 큰 값이 1등, `1`이면 작은 값이 1등

정확히 말하면 앞의 2개 인수는 필수이고, 마지막 인수는 선택이다. 하지만 처음 배울 때는 헷갈리지 않게 `0` 또는 `1`을 직접 써 주는 편이 좋다.

### 실습: 점수 높은 순서대로 순위 구하기

H4에 아래 수식을 입력한다.

```excel
=RANK(G4, $G$4:$G$10, 0)
```

그리고 H10까지 자동 채우기 한다.

여기서 중요한 부분은 `$G$4:$G$10`이다. 만약 `$` 없이 `G4:G10`으로 쓰면 H5로 자동 채우기 했을 때 비교 범위가 `G5:G11`처럼 같이 밀려버린다. 그러면 전체 점수 7개를 기준으로 순위를 매기는 게 아니라, 엉뚱한 범위를 기준으로 순위를 매기게 된다.

예상 결과는 다음과 같다.

| 행 | 점수 | 수식 결과 |
| --- | ---: | ---: |
| 4 | 88 | 4 |
| 5 | 95 | 2 |
| 6 | 72 | 6 |
| 7 | 88 | 4 |
| 8 | 100 | 1 |
| 9 | 64 | 7 |
| 10 | 91 | 3 |

88점이 두 명이라서 둘 다 4등이 된다. 대신 그 다음 순위는 5등이 아니라 6등으로 넘어간다.

작은 값이 1등이 되게 하려면 마지막 인자를 `1`로 바꾼다.

```excel
=RANK(G4, $G$4:$G$10, 1)
```

## 3. SUMIF: 조건에 맞는 값만 더하기

`SUMIF`는 "조건을 만족하는 행의 값만 더해줘"라고 시킬 때 쓰는 함수다.

```excel
=SUMIF(범위, 조건, [합계범위])
```

- 범위: 조건을 검사할 곳
- 조건: 찾고 싶은 값이나 조건
- 합계범위: 실제로 더할 숫자가 있는 곳

### 실습: 중부 지점 매출만 더하기

아무 빈 셀에 아래 수식을 입력해보자.

```excel
=SUMIF($C$4:$C$10, "중부", $D$4:$D$10)
```

이 수식은 C4부터 C10까지 보면서 값이 `"중부"`인 행을 찾는다. 그리고 같은 행의 D열 매출을 더한다.

중부는 4행, 6행, 9행에 있으므로 계산은 이렇게 된다.

```text
1200000 + 980000 + 830000 = 3010000
```

따라서 결과는 `3010000`이다.

여기서도 범위를 `$C$4:$C$10`, `$D$4:$D$10`처럼 고정해두면 자동 채우기를 하거나 수식을 복사할 때 범위가 밀리지 않는다.

## 4. MAX, MIN: 최댓값과 최솟값 구하기

`MAX`는 범위 안에서 가장 큰 값을 찾고, `MIN`은 가장 작은 값을 찾는다.

```excel
=MAX($G$4:$G$10)
=MIN($G$4:$G$10)
```

실습 표에서 점수의 최댓값은 `100`, 최솟값은 `64`다.

매출에서 가장 큰 값을 찾고 싶다면 범위를 D열로 바꾸면 된다.

```excel
=MAX($D$4:$D$10)
=MIN($D$4:$D$10)
```

## 5. COUNT, COUNTA, COUNTBLANK: 개수 세기

개수를 세는 함수는 이름이 비슷해서 헷갈리기 쉽다.

| 함수 | 의미 | 예시 |
| --- | --- | --- |
| `COUNT` | 숫자가 들어 있는 셀만 센다 | 매출, 점수 |
| `COUNTA` | 비어 있지 않은 셀을 센다 | 숫자와 문자 모두 포함 |
| `COUNTBLANK` | 빈칸을 센다 | 아직 입력하지 않은 칸 |

### 실습

매출 칸에는 숫자가 7개 들어 있다.

```excel
=COUNT($D$4:$D$10)
```

결과는 `7`이다.

담당자 칸은 E8이 비어 있다. 그래서 비어 있지 않은 담당자 수는 6명이다.

```excel
=COUNTA($E$4:$E$10)
```

결과는 `6`이다.

빈칸 수를 세면 E8 하나만 비어 있으므로 결과는 1이다.

```excel
=COUNTBLANK($E$4:$E$10)
```

결과는 `1`이다.

처음에는 이렇게 외우면 쉽다.

- `COUNT`: 숫자만
- `COUNTA`: 뭐라도 들어 있으면
- `COUNTBLANK`: 비어 있으면

## 6. LEFT, RIGHT, MID: 문자열 자르기

문자열 함수는 엑셀에서 텍스트를 필요한 만큼 잘라낼 때 쓴다. 파이썬의 문자열 슬라이싱과 느낌이 비슷하다.

### LEFT

`LEFT`는 왼쪽에서부터 원하는 글자 수만큼 가져온다.

```excel
=LEFT("ABCDE", 2)
```

결과는 `AB`다.

F4에 `ABCDE`가 들어 있으므로 아래처럼 셀을 참조해도 된다.

```excel
=LEFT(F4, 2)
```

### RIGHT

`RIGHT`는 오른쪽에서부터 원하는 글자 수만큼 가져온다.

```excel
=RIGHT("ABCDE", 2)
```

결과는 `DE`다.

### MID

`MID`는 중간에서 일부를 가져올 때 쓴다.

```excel
=MID(문자열, 시작위치, 가져올글자수)
```

엑셀의 글자 위치는 1부터 센다.

```excel
=MID("ABCDE", 2, 3)
```

2번째 글자인 `B`부터 3글자를 가져오므로 결과는 `BCD`다.

실습 표의 코드에서 앞 2글자, 뒤 2글자, 가운데 3글자를 뽑아보면 이렇게 쓸 수 있다.

```excel
=LEFT(F4, 2)
=RIGHT(F4, 2)
=MID(F4, 2, 3)
```

F4가 `ABCDE`라면 결과는 차례대로 `AB`, `DE`, `BCD`다.

## 7. ROUND, ROUNDDOWN, ROUNDUP: 반올림과 올림/내림

숫자를 원하는 자리에서 정리할 때 쓰는 함수들이다.

```excel
=ROUND(숫자, 자릿수)
=ROUNDDOWN(숫자, 자릿수)
=ROUNDUP(숫자, 자릿수)
```

여기서 자릿수가 헷갈릴 수 있다.

- `1`: 소수 첫째 자리까지 남김
- `2`: 소수 둘째 자리까지 남김
- `0`: 정수까지 남김
- `-1`: 십의 자리로 정리
- `-2`: 백의 자리로 정리

### ROUND: 일반적인 반올림

```excel
=ROUND(1.234, 1)
```

소수 첫째 자리까지 남기므로 결과는 `1.2`다.

```excel
=ROUND(1234, -2)
```

백의 자리 기준으로 반올림하므로 결과는 `1200`이다.

### ROUNDDOWN: 무조건 버림

```excel
=ROUNDDOWN(1.255, 1)
```

소수 첫째 자리까지만 남기고 뒤는 버린다. 결과는 `1.2`다.

### ROUNDUP: 무조건 올림

```excel
=ROUNDUP(1.234, 2)
```

소수 둘째 자리까지 남긴다. 셋째 자리 이하에 값이 있으므로 둘째 자리에서 올림 처리되어 결과는 `1.24`다.

## 한 번에 복습하기

아래 문제를 직접 풀어보면 오늘 함수들을 한 번에 확인할 수 있다.

1. H4:H10에 점수 높은 순위 구하기
2. 빈 셀에 중부 지점 매출 합계 구하기
3. 점수의 최댓값과 최솟값 구하기
4. 담당자 칸에서 비어 있지 않은 셀 개수 구하기
5. 담당자 칸에서 빈칸 개수 구하기
6. F4의 코드 `ABCDE`에서 왼쪽 2글자, 오른쪽 2글자, 2번째 글자부터 3글자 뽑기
7. `1.234`, `1.255`, `1234`를 ROUND 계열 함수로 정리하기

정답은 아래와 같다.

```excel
=RANK(G4, $G$4:$G$10, 0)
=SUMIF($C$4:$C$10, "중부", $D$4:$D$10)
=MAX($G$4:$G$10)
=MIN($G$4:$G$10)
=COUNTA($E$4:$E$10)
=COUNTBLANK($E$4:$E$10)
=LEFT(F4, 2)
=RIGHT(F4, 2)
=MID(F4, 2, 3)
=ROUND(1.234, 1)
=ROUNDDOWN(1.255, 1)
=ROUNDUP(1.234, 2)
=ROUND(1234, -2)
```

## 정리

이번에 배운 함수들은 시험이나 실무에서 정말 자주 만나는 기본기다.

특히 중요한 건 함수 이름만 외우는 게 아니라, 자동 채우기를 했을 때 어떤 셀은 움직여야 하고 어떤 범위는 고정되어야 하는지 구분하는 것이다.

- 한 행씩 내려가며 계산할 값은 보통 상대 참조로 둔다.
- 전체 비교 범위나 전체 합계 범위는 절대 참조로 고정한다.
- `F4` 단축키로 `$` 위치를 빠르게 바꿀 수 있다.
- `COUNT`, `COUNTA`, `COUNTBLANK`는 "무엇을 세는지"가 다르다.
- `LEFT`, `RIGHT`, `MID`는 문자열을 필요한 부분만 잘라낼 때 쓴다.
- `ROUND`, `ROUNDDOWN`, `ROUNDUP`은 숫자를 원하는 자리에서 정리할 때 쓴다.

처음에는 수식이 길어 보여도, 직접 표에 넣고 자동 채우기를 해보면 왜 절대 참조가 필요한지 훨씬 선명하게 이해된다.
