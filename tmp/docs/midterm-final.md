# 컴활 중간고사 최종 정리: 엑셀 기초부터 함수, 필터, 사용자 지정 서식까지

시험 직전에 제일 위험한 건 "대충 본 적은 있는데, 막상 문제로 나오면 손이 안 움직이는 상태"다.

그래서 이번 정리본은 단순 암기표가 아니라, 초보자도 바로 따라 하면서 이해할 수 있게 구성했다. 목표는 하나다.

> 엑셀에서 값이 어떻게 입력되고, 어떻게 보이고, 어떤 함수로 계산되는지 구분하기.

## 0. 시험 전 최우선 암기 목록

아래는 먼저 외워두면 좋은 핵심이다.

| 구분 | 꼭 기억할 것 |
| --- | --- |
| 셀 주소 | 열 알파벳 + 행 숫자, 예: `A1` |
| 엑셀 구조 | 셀 < 워크시트 < 통합 문서 |
| 수식 시작 | 모든 함수는 `=`로 시작 |
| 절대 참조 | `$A$1`, 자동 채우기해도 고정 |
| 셀 서식 창 | `Ctrl + 1` |
| 수식 보기 | `Ctrl + ~` |
| 오늘 날짜 | `Ctrl + ;` |
| 현재 시간 | `Ctrl + Shift + ;` |
| 한 셀 줄바꿈 | `Alt + Enter` |
| 전체 데이터 선택 | `Ctrl + Shift + *` |

## 1. 엑셀 기본 구조

엑셀은 그냥 표처럼 보이지만, 실제로는 데이터를 셀 단위로 저장하고 계산하는 도구다.

```text
셀(Cell) < 워크시트(Worksheet) < 통합 문서(Workbook)
```

- 셀: 데이터를 입력하는 가장 작은 칸
- 워크시트: 셀들이 모여 있는 한 장의 시트
- 통합 문서: 여러 워크시트를 담는 엑셀 파일 전체

셀 주소는 열과 행이 만나는 위치다.

```text
A1 = A열 1행
C4 = C열 4행
G10 = G열 10행
```

시험에서 `G4` 같은 주소가 나오면 "G열의 4번째 행"이라고 읽으면 된다.

## 2. 데이터 입력법

엑셀은 입력한 데이터의 종류에 따라 다르게 인식한다.

| 데이터 | 입력 방법 | 예시 |
| --- | --- | --- |
| 숫자 | 그냥 입력 | `1000` |
| 날짜 | 하이픈 또는 슬래시 사용 | `2026-04-21`, `2026/04/21` |
| 분수 | `0` 입력 후 한 칸 띄우고 입력 | `0 1/2` |
| 특수 문자 | 한글 자음 입력 후 `한자` 키 | `ㅁ` + `한자` |

특수 문자는 자음마다 자주 나오는 종류가 다르다.

| 자음 | 자주 쓰는 기호 |
| --- | --- |
| `ㅁ` | 일반 기호: ★, ■ |
| `ㄷ` | 수학 기호: ±, ≠ |
| `ㄹ` | 단위 기호: ℃, ￥ |

분수를 입력할 때 `1/2`만 쓰면 날짜처럼 인식될 수 있다. 그래서 분수는 `0 1/2`처럼 0을 먼저 쓰고 한 칸 띄운다.

## 3. 자동 채우기와 참조

엑셀 시험에서 실수 많이 나는 부분이 자동 채우기다.

수식을 아래로 복사하면 셀 주소도 같이 움직인다. 이 움직임을 막으려면 `$`를 붙인다.

### 상대 참조

```excel
G4
```

`G4`는 상대 참조다. 아래로 자동 채우기하면 `G5`, `G6`, `G7`처럼 같이 내려간다.

### 절대 참조

```excel
$G$4:$G$10
```

`$`가 붙은 부분은 고정된다. 순위처럼 전체 범위를 계속 기준으로 삼아야 할 때 필요하다.

```excel
=RANK(G4, $G$4:$G$10, 0)
```

여기서 `G4`는 각 행의 점수이므로 내려가면서 바뀌어야 한다. 하지만 `$G$4:$G$10`은 전체 점수 범위이므로 고정되어야 한다.

### 혼합 참조

```excel
$G4
G$4
```

- `$G4`: G열은 고정, 행은 움직임
- `G$4`: 열은 움직임, 4행은 고정

참조 형태는 셀 주소에 커서를 둔 뒤 `F4`를 누르면 바뀐다.

```text
G4 -> $G$4 -> G$4 -> $G4 -> G4
```

## 4. 셀 서식: 값과 보이는 모양은 다르다

사용자 지정 서식은 "값 자체"를 바꾸는 기능이 아니다. 값은 그대로 두고 화면에 보이는 모양만 바꾼다.

예를 들어 실제 값이 `1000`이어도 서식을 어떻게 입히느냐에 따라 이렇게 보일 수 있다.

```text
#,##0        -> 1,000
[빨강]#,##0 -> 빨간 1,000
0.0%         -> 100000.0%
```

여기서 중요한 말은 이거다.

> 사용자 지정 서식은 값이 아니라 겉모습을 바꾼다.

## 5. 사용자 지정 서식 기본 구조

사용자 지정 서식은 세미콜론 `;`으로 구역을 나눈다.

```text
양수;음수;0;텍스트
```

예를 들어:

```text
#,##0;[빨강]-#,##0;0;@
```

뜻은 다음과 같다.

- 양수: 천 단위 쉼표로 표시
- 음수: 빨강 + 마이너스 + 천 단위 쉼표
- 0: 그냥 0으로 표시
- 텍스트: 입력된 문자 그대로 표시

## 6. `#`, `0`, `,`, `.`, `@` 한 번에 이해하기

사용자 지정 서식에서 자주 나오는 기호는 딱 5개다.

| 기호 | 뜻 | 예시 |
| --- | --- | --- |
| `#` | 숫자가 있으면 표시, 없으면 생략 | `#` |
| `0` | 숫자가 없어도 0을 채워 표시 | `000` |
| `,` | 천 단위 구분 쉼표 | `#,##0` |
| `.` | 소수점 자리 표시 | `0.00` |
| `@` | 입력된 문자 그대로 표시 | `[파랑]@` |

### `#` 예시

```text
#
```

- 값 `5` -> `5`
- 값 `0` -> 안 보일 수 있음

`#`는 필요한 숫자만 보여주는 기호다.

### `0` 예시

```text
000
```

- 값 `5` -> `005`
- 값 `23` -> `023`
- 값 `123` -> `123`

`0`은 자리수를 강제로 채우는 기호다.

### `#,##0` 예시

```text
#,##0
```

- 값 `5` -> `5`
- 값 `500` -> `500`
- 값 `1000` -> `1,000`
- 값 `12000` -> `12,000`

시험에서 숫자에 천 단위 쉼표를 넣으라고 하면 거의 `#,##0`을 떠올리면 된다.

### 소수점 예시

```text
#,##0.0
```

- 값 `1234` -> `1,234.0`
- 값 `1234.56` -> `1,234.6`

```text
#,##0.00
```

- 값 `1234` -> `1,234.00`
- 값 `1234.5` -> `1,234.50`

`.0`은 소수 첫째 자리, `.00`은 소수 둘째 자리까지 보여준다.

## 7. 조건부 사용자 지정 서식

조건을 넣으면 "이 조건에 맞으면 이 모양으로 보여줘"라는 뜻이 된다.

### 1000 이상은 빨강, 나머지 숫자는 파랑

```text
[빨강][>=1000]#,##0;[파랑]#,##0
```

뜻은 이렇게 읽으면 된다.

- 1000 이상 숫자: 빨강 + 천 단위 쉼표
- 그 외 숫자: 파랑 + 천 단위 쉼표

예시:

| 값 | 표시 |
| ---: | --- |
| 800 | 파랑 `800` |
| 1000 | 빨강 `1,000` |
| 1200 | 빨강 `1,200` |
| 300 | 파랑 `300` |

### 왜 `[빨강][>=1000]#,##0;[파랑]`은 위험할까?

```text
[빨강][>=1000]#,##0;[파랑]
```

이 서식은 앞부분은 완성되어 있다.

```text
[빨강][>=1000]#,##0
```

- `[빨강]`: 글자 색을 빨강으로
- `[>=1000]`: 값이 1000 이상이면
- `#,##0`: 천 단위 쉼표로 표시

그런데 뒤쪽 `[파랑]`은 색만 있고 숫자를 어떻게 표시할지 빠져 있다.

시험에서는 애매하게 쓰지 말고 아래처럼 완성형으로 쓰는 것이 안전하다.

```text
[빨강][>=1000]#,##0;[파랑]#,##0
```

### 자주 나오는 사용자 지정 서식 암기

| 조건 | 서식 |
| --- | --- |
| 천 단위 쉼표 | `#,##0` |
| 소수 첫째 자리 | `0.0` |
| 소수 둘째 자리 | `0.00` |
| 퍼센트 소수 첫째 자리 | `0.0%` |
| 텍스트 그대로 | `@` |
| 텍스트 파랑 | `[파랑]@` |
| 양수 파랑, 음수 빨강 | `[파랑]#,##0;[빨강]-#,##0` |
| 1000 이상 빨강, 나머지 파랑 | `[빨강][>=1000]#,##0;[파랑]#,##0` |
| 0을 하이픈으로 표시 | `#,##0;[빨강]-#,##0;-` |

텍스트만 파랑으로 표시하라는 문제가 나오면 텍스트 구역만 쓰는 방식도 알아두면 좋다.

```text
;;;[파랑]@
```

앞의 숫자 구역 3개를 비우고, 네 번째 텍스트 구역만 파랑으로 지정한 것이다.

## 8. 필터: 자동 필터와 고급 필터

필터는 많은 데이터 중에서 원하는 조건에 맞는 행만 골라 보는 기능이다.

### 자동 필터

자동 필터는 표 머리글의 목록 단추를 눌러 조건을 고르는 방식이다.

- 단순 선택
- 오름차순/내림차순 정렬
- 특정 값만 보기
- 숫자 필터, 텍스트 필터

조건이 단순할 때 사용한다.

### 고급 필터

고급 필터는 조건을 다른 셀 영역에 직접 써서 복잡한 조건을 걸 때 쓴다.

핵심은 AND와 OR의 위치다.

| 조건 관계 | 작성 위치 | 뜻 |
| --- | --- | --- |
| AND | 같은 행 | A이면서 B |
| OR | 다른 행 | A이거나 B |

예를 들어 "지역이 중부이고 매출이 1000000 이상"이면 조건을 같은 행에 쓴다.

```text
지역      매출
중부      >=1000000
```

"지역이 중부이거나 남부"이면 조건을 다른 행에 쓴다.

```text
지역
중부
남부
```

시험에서는 이 문장을 외워두면 된다.

> 고급 필터에서 AND는 같은 행, OR은 다른 행.

## 10. 기초 통계 함수

모든 함수는 `=`으로 시작한다.

### 합계와 평균

```excel
=SUM(D4:D10)
=AVERAGE(D4:D10)
```

- `SUM`: 범위의 합계를 구한다.
- `AVERAGE`: 범위의 평균을 구한다.

### 최댓값과 최솟값

```excel
=MAX(G4:G10)
=MIN(G4:G10)
```

- `MAX`: 가장 큰 값
- `MIN`: 가장 작은 값

실습 표에서 점수 최댓값은 `100`, 최솟값은 `64`다.

## 11. COUNT 계열 함수

개수 세기 함수는 이름이 비슷해서 시험에서 자주 헷갈린다.

| 함수 | 세는 것 |
| --- | --- |
| `COUNT` | 숫자가 들어 있는 셀 |
| `COUNTA` | 비어 있지 않은 셀 |
| `COUNTBLANK` | 빈칸 |

실습:

```excel
=COUNT(D4:D10)
=COUNTA(E4:E10)
=COUNTBLANK(E4:E10)
```

예상 결과:

- `COUNT(D4:D10)` -> `7`
- `COUNTA(E4:E10)` -> `6`
- `COUNTBLANK(E4:E10)` -> `1`

암기법은 간단하다.

```text
COUNT = 숫자만
COUNTA = 뭐라도 있으면
COUNTBLANK = 비어 있으면
```

## 12. SUMIF: 조건에 맞는 값만 더하기

`SUMIF`는 조건에 맞는 행의 숫자만 더한다.

```excel
=SUMIF(범위, 조건, 합계범위)
```

중부 지점 매출만 더하려면:

```excel
=SUMIF($C$4:$C$10, "중부", $D$4:$D$10)
```

뜻:

- `$C$4:$C$10`: 지점 이름을 검사
- `"중부"`: 중부인지 확인
- `$D$4:$D$10`: 조건이 맞는 행의 매출을 더함

중부는 4행, 6행, 9행이다.

```text
1200000 + 980000 + 830000 = 3010000
```

결과는 `3010000`이다.

여기서 범위를 `$`로 고정한 이유는 수식을 복사해도 검사 범위가 밀리지 않게 하기 위해서다.

## 13. RANK: 순위 구하기

`RANK`는 어떤 값이 전체 범위에서 몇 등인지 구한다.

```excel
=RANK(기준값, 전체범위, 옵션)
```

- 옵션 `0`: 큰 값이 1등
- 옵션 `1`: 작은 값이 1등

점수 높은 순서대로 순위를 구하려면:

```excel
=RANK(G4, $G$4:$G$10, 0)
```

가장 중요한 부분은 `$G$4:$G$10`이다. 전체 점수 범위는 자동 채우기해도 고정되어야 한다.

만약 `$` 없이 `G4:G10`으로 쓰면 아래로 복사할 때 `G5:G11`, `G6:G12`처럼 범위가 밀려서 순위가 이상해질 수 있다.

예상 결과:

| 점수 | 순위 |
| ---: | ---: |
| 88 | 4 |
| 95 | 2 |
| 72 | 6 |
| 88 | 4 |
| 100 | 1 |
| 64 | 7 |
| 91 | 3 |

88점이 두 명이라 둘 다 4등이고, 다음 순위는 5등이 아니라 6등으로 넘어간다.

## 14. IF와 중첩 IF

`IF`는 조건에 따라 다른 값을 보여준다.

```excel
=IF(조건, 참일_때_값, 거짓일_때_값)
```

예를 들어 달성률이 100% 이상이면 "달성", 아니면 "미달성"을 표시하려면:

```excel
=IF(H4>=100%, "달성", "미달성")
```

조건이 여러 단계면 `IF` 안에 `IF`를 한 번 더 넣는다.

```excel
=IF(H4>=120%, 400, IF(H4>=100%, 200, ""))
```

뜻:

- H4가 120% 이상이면 `400`
- 아니고 H4가 100% 이상이면 `200`
- 그것도 아니면 빈칸

이 수식은 위에서부터 차례대로 검사한다.

```text
120% 이상인가?
맞으면 400
아니면 100% 이상인가?
맞으면 200
아니면 빈칸
```

## 15. 문자열 함수: LEFT, RIGHT, MID

문자열 함수는 글자를 잘라낼 때 쓴다.

### LEFT

왼쪽에서부터 가져온다.

```excel
=LEFT("ABCDE", 2)
```

결과:

```text
AB
```

### RIGHT

오른쪽에서부터 가져온다.

```excel
=RIGHT("ABCDE", 2)
```

결과:

```text
DE
```

### MID

중간에서 가져온다.

```excel
=MID("ABCDE", 2, 3)
```

엑셀은 글자 위치를 1부터 센다. 2번째 글자인 `B`부터 3글자를 가져오므로 결과는 `BCD`다.

```text
A B C D E
1 2 3 4 5
```

## 16. 반올림 함수: ROUND, ROUNDDOWN, ROUNDUP

숫자를 원하는 자리에서 정리할 때 쓴다.

```excel
=ROUND(숫자, 자릿수)
=ROUNDDOWN(숫자, 자릿수)
=ROUNDUP(숫자, 자릿수)
```

| 자릿수 | 뜻 |
| ---: | --- |
| `2` | 소수 둘째 자리까지 |
| `1` | 소수 첫째 자리까지 |
| `0` | 정수까지 |
| `-1` | 십의 자리 |
| `-2` | 백의 자리 |

예시:

```excel
=ROUND(1.234, 1)
```

결과는 `1.2`다.

```excel
=ROUNDDOWN(1.255, 1)
```

결과는 `1.2`다. 뒤를 무조건 버린다.

```excel
=ROUNDUP(1.234, 2)
```

결과는 `1.24`다. 뒤에 남는 숫자가 있으면 올린다.

```excel
=ROUND(1234, -2)
```

결과는 `1200`이다. 백의 자리 기준으로 반올림한다.

## 17. 사용자 정의 목록

엑셀은 기본적으로 숫자나 날짜는 자동 채우기가 잘 된다.

하지만 `주임 -> 과장 -> 부장`처럼 엑셀에 없는 순서를 자동 채우기하려면 사용자 정의 목록에 등록해야 한다.

경로:

```text
파일 -> 옵션 -> 고급 -> 사용자 지정 목록 편집
```

시험에서 "엑셀에 없는 순서로 자동 채우기"라는 말이 나오면 사용자 정의 목록을 떠올리면 된다.

## 20. 마지막 100점 체크리스트

시험장 들어가기 전에 아래 질문에 바로 답할 수 있으면 훨씬 안정적이다.

- `A1`은 A열 1행이라는 뜻이다.
- 함수는 반드시 `=`으로 시작한다.
- 자동 채우기 때 범위를 고정하려면 `$`를 붙인다.
- `RANK(G4, $G$4:$G$10, 0)`에서 전체 범위는 절대 참조다.
- `SUMIF`는 조건을 검사할 범위와 실제 더할 범위가 다를 수 있다.
- `COUNT`는 숫자만 세고, `COUNTA`는 비어 있지 않으면 세고, `COUNTBLANK`는 빈칸을 센다.
- `LEFT`, `RIGHT`, `MID`는 문자열을 자른다.
- `ROUND`, `ROUNDDOWN`, `ROUNDUP`은 숫자를 원하는 자리에서 정리한다.
- 사용자 지정 서식의 `#`는 있으면 표시, `0`은 없으면 채움이다.
- `#,##0`은 천 단위 쉼표 표시다.
- `@`는 텍스트 그대로 표시다.
- 사용자 지정 서식은 값을 바꾸는 것이 아니라 보이는 모양만 바꾼다.
- 고급 필터에서 AND는 같은 행, OR은 다른 행이다.
- 사용자 정의 목록은 엑셀에 없는 순서로 자동 채우기할 때 쓴다.

이번 시험 범위는 "어려운 기능을 많이 아는가"보다 "기본 개념을 헷갈리지 않는가"가 더 중요해 보인다.

특히 절대 참조, 사용자 지정 서식, `SUMIF`, `RANK`, `IF`는 문제로 나오면 손으로 바로 써야 하는 부분이라 마지막까지 직접 입력해보는 게 좋다.
